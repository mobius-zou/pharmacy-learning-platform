使用说明

人工校对是硬性关卡：抽取结果先进入 ChromaDB 草稿区， 只有点击「确认入库」才会写入 MySQL 的 knowledge_graph 表。

未配置 LLM 时，PICO-D 与三元组由本地规则抽取（ 无 Agent 降级模式），结果需人工修正后再入库。

「知识点转卡片」会把选中的知识点写入复习系统，并按知识点打上章节标签。
